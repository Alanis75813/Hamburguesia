# Hamburguesia

Nesse site de uma hamburgueria ficticia o usuário pode criar sua conta, realizar pedidos e confirmar pelo o whatzapp 
que um motoboy/girl enviará até onde estiver. Além de saber um pouco da história e horário de funcionamento.
Um menu super interativo e diversificado.

TECNOLOGIAS USADAS:
HTML CSS JAVASCRIPT E JQUERY (BIBLIOTECA DO JS)
